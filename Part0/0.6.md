    activate server
    server-->>browser: JSON containing the existing notes

    Note right of browser: JavaScript renders the existing notes. User types a new note and clicks Save, JavaScript prevents the form's default submission. JavaScript adds the new note to the list and redraws it

    browser->>server: POST https://studies.cs.helsinki.fi/exampleapp/new_note_spa
    Note right of browser: The request body contains the note and date as JSON
    activate server
    server-->>browser: HTTP status code 201 Created
    deactivate server
